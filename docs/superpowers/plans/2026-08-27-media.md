# Media (videos + brochures) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace IDAP's images-only `Institution.gallery[]` with a unified `media[]` domain carrying images, external video links, brochures and prospectuses — manageable in the dashboard, exposed on the public API, and mappable to FeesBasket.

**Architecture:** One embedded array on `Institution` with a `kind` discriminator, mirroring FeesBasket's own media model 1:1. Videos are YouTube/Vimeo URLs normalised at entry (never uploaded); documents are PDFs stored through the existing `storage.putPublic` path. Two pure helper modules — video-URL normalisation and public-URL resolution — carry the logic that is easy to get wrong, so it is unit-testable without HTTP or a database.

**Tech Stack:** Next.js 16 App Router, Mongoose 8, Zod 4, TypeScript, Vitest 3, react-hook-form, Radix/shadcn, Tailwind v4.

**Spec:** `docs/superpowers/specs/2026-08-27-media-design.md`

**Contract reference (binding, outranks this plan):** `docs/integrations/feesbasket-api-map.md` §4 "Media". Where this plan and that file disagree about FeesBasket's behaviour, **the map wins** — it was read from live route handlers. Report any disagreement rather than silently following either.

```ts
// src/lib/media/video-url.ts
import { MEDIA_PROVIDERS } from "@/lib/constants";

export type MediaProvider = (typeof MEDIA_PROVIDERS)[number];

export type NormalizedVideo = {
  provider: MediaProvider;
  videoId: string;
  url: string;
};

/**
 * An explicit host allowlist, never a substring or regex match on the whole
 * URL. `youtube.com.evil.example` contains "youtube.com" and would satisfy a
 * loose match while being an entirely different origin, so hosts are compared
 * for exact equality after stripping a leading `www.`.
 */
const YOUTUBE_HOSTS = new Set(["youtube.com", "m.youtube.com", "youtu.be"]);
const VIMEO_HOSTS = new Set(["vimeo.com", "player.vimeo.com"]);

const YOUTUBE_ID = /^[A-Za-z0-9_-]{11}$/;
const VIMEO_ID = /^\d+$/;

function host(url: URL): string {
  return url.hostname.toLowerCase().replace(/^www\./, "");
}

function youtubeId(url: URL, h: string): string | null {
  if (h === "youtu.be") return url.pathname.slice(1) || null;
  const segments = url.pathname.split("/").filter(Boolean);
  if (segments[0] === "embed" || segments[0] === "shorts") return segments[1] ?? null;
  if (url.pathname === "/watch") return url.searchParams.get("v");
  return null;
}

export function normalizeVideoUrl(input: string): NormalizedVideo | null {
  const trimmed = input.trim();
  if (!trimmed) return null;

  let url: URL;
  try {
    url = new URL(trimmed);
  } catch {
    return null;
  }

  // Anything other than http(s) — `javascript:`, `data:` — is refused before
  // the host is even considered.
  if (url.protocol !== "https:" && url.protocol !== "http:") return null;

  const h = host(url);

  if (YOUTUBE_HOSTS.has(h)) {
    const videoId = youtubeId(url, h);
    if (!videoId || !YOUTUBE_ID.test(videoId)) return null;
    return {
      provider: "YOUTUBE",
      videoId,
      url: `https://www.youtube.com/watch?v=${videoId}`,
    };
  }

  if (VIMEO_HOSTS.has(h)) {
    const segments = url.pathname.split("/").filter(Boolean);
    const videoId = h === "player.vimeo.com" ? segments[1] : segments[0];
    if (!videoId || !VIMEO_ID.test(videoId)) return null;
    return { provider: "VIMEO", videoId, url: `https://vimeo.com/${videoId}` };
  }

  return null;
}
```

### Task 2: Public URL resolution and reachability guard

**Files:**
- Create: `src/lib/media/public-url.ts`
- Test: `tests/unit/public-url.test.ts`

**Interfaces:**
- Consumes: `env.APP_URL` from `@/lib/env`.
- Produces: `toPublicUrl(url: string): string` and `assertExternallyReachable(url: string): void` (throws `AppError`). Tasks 6 and 7 consume both.

**Why two functions and not one.** `storage.putPublic` returns a **relative** `/api/media/{key}` on the local-disk backend and an absolute `https://…` on Vercel Blob, so stored values differ in kind between backends. Both the public API and the FeesBasket push need absolute URLs — but only the push needs the host to be reachable from outside this machine. `env.APP_URL` **never returns unset**: it defaults to `"http://localhost:3000"` (`src/lib/env.ts:16-17`), so a naive "throw if unset" guard would never fire and IDAP would push well-formed, permanently-dead `localhost` links to a live public listing.

```ts
// src/lib/media/public-url.ts
import { env } from "@/lib/env";
import { AppError } from "@/lib/api/errors";

/**
 * Resolves a stored media value to an absolute URL.
 *
 * `storage.putPublic` returns `/api/media/{key}` on the local-disk backend and
 * an absolute `https://…` on Vercel Blob, so callers cannot assume either
 * shape. This is the single place that reconciles them.
 */
export function toPublicUrl(url: string): string {
  if (/^https?:\/\//i.test(url)) return url;
  const base = env.APP_URL.replace(/\/+$/, "");
  const path = url.startsWith("/") ? url : `/${url}`;
  return `${base}${path}`;
}

const PRIVATE_V4 =
  /^(10\.|127\.|192\.168\.|169\.254\.|172\.(1[6-9]|2\d|3[01])\.)/;

/**
 * Refuses a URL that cannot be resolved from outside this machine.
 *
 * Used ONLY on the outbound partner path, never on IDAP's own public API
 * (where a localhost URL in development is harmless). FeesBasket links to the
 * URL IDAP supplies and never fetches a copy of the bytes
 * (`feesbasket-api-map.md` §4), so a localhost URL there is a permanently dead
 * link on a public listing that IDAP has no way to observe. Failing the sync
 * loudly beats publishing a broken one quietly.
 *
 * `env.APP_URL` defaults to `http://localhost:3000` (`src/lib/env.ts:16-17`)
 * rather than being unset, which is exactly why this checks the resolved host
 * rather than whether the variable was configured.
 */
export function assertExternallyReachable(url: string): void {
  let parsed: URL;
  try {
    parsed = new URL(url);
  } catch {
    throw new AppError(
      "VALIDATION_ERROR",
      `Media URL "${url}" is not an absolute URL, so it is not reachable from outside this server. Set NEXT_PUBLIC_APP_URL to this deployment's public address.`,
    );
  }

  const hostname = parsed.hostname.toLowerCase();
  const isLoopback =
    hostname === "localhost" || hostname === "::1" || hostname === "[::1]";

  if (isLoopback || PRIVATE_V4.test(hostname)) {
    throw new AppError(
      "VALIDATION_ERROR",
      `Media URL host "${hostname}" is not reachable from outside this server, so partners would receive a dead link. Set NEXT_PUBLIC_APP_URL to this deployment's public address.`,
    );
  }
}
```

```ts
import { makeInstitution } from "@/tests/helpers/factories";
import { migrateGalleryToMedia } from "@/../scripts/migrate-gallery-to-media";

describe("gallery → media migration", () => {
  beforeEach(async () => {
    await Institution.deleteMany({});
  });

  it("moves a legacy gallery item into media as an IMAGE", async () => {
    await makeInstitution("INS0001");
    await Institution.collection.updateOne(
      { institutionId: "INS0001" },
      {
        $set: {
          gallery: [
            {
              _id: new (await import("mongoose")).Types.ObjectId(),
              imageUrl: "/api/media/media/INS0001/a.png",
              title: "Campus",
              description: "The main block",
              sortOrder: 2,
              status: "HIDDEN",
              uploadedAt: new Date("2026-01-01"),
            },
          ],
        },
      },
    );

    const report = await migrateGalleryToMedia({ apply: true });

    expect(report.migrated).toBe(1);
    const row = await Institution.collection.findOne({ institutionId: "INS0001" });
    expect(row?.gallery).toBeUndefined();
    expect(row?.media).toHaveLength(1);
    expect(row?.media[0]).toMatchObject({
      kind: "IMAGE",
      url: "/api/media/media/INS0001/a.png",
      title: "Campus",
      caption: "The main block",
      sortOrder: 2,
      status: "HIDDEN",
    });
  });

  it("is idempotent — a second run migrates nothing", async () => {
    await makeInstitution("INS0002");
    await Institution.collection.updateOne(
      { institutionId: "INS0002" },
      { $set: { gallery: [{ imageUrl: "/api/media/x.png", status: "ACTIVE" }] } },
    );

    await migrateGalleryToMedia({ apply: true });
    const second = await migrateGalleryToMedia({ apply: true });

    expect(second.migrated).toBe(0);
  });

  // MUTATION-DISTINGUISHING: silent truncation would satisfy every other test
  // here. This is the one that fails if the script shortens instead of refusing.
  it("refuses a description longer than the caption cap, without writing", async () => {
    await makeInstitution("INS0003");
    const long = "x".repeat(241);
    await Institution.collection.updateOne(
      { institutionId: "INS0003" },
      { $set: { gallery: [{ imageUrl: "/api/media/x.png", description: long, status: "ACTIVE" }] } },
    );

    const report = await migrateGalleryToMedia({ apply: true });

    expect(report.migrated).toBe(0);
    expect(report.overlong).toHaveLength(1);
    expect(report.overlong[0]).toMatchObject({ institutionId: "INS0003", length: 241 });

    const row = await Institution.collection.findOne({ institutionId: "INS0003" });
    expect(row?.media).toBeUndefined();
    expect(row?.gallery).toHaveLength(1);
  });

  it("does not write anything in dry-run mode", async () => {
    await makeInstitution("INS0004");
    await Institution.collection.updateOne(
      { institutionId: "INS0004" },
      { $set: { gallery: [{ imageUrl: "/api/media/x.png", status: "ACTIVE" }] } },
    );

    const report = await migrateGalleryToMedia({ apply: false });

    expect(report.migrated).toBe(1);
    const row = await Institution.collection.findOne({ institutionId: "INS0004" });
    expect(row?.media).toBeUndefined();
  });
});
```

Rules:

`addMediaDocument` follows `addMediaImage`'s existing shape exactly — same atomic per-kind `$expr` cap filter, same `storage.deletePublic` rollback when the cap rejects the push, same `ActivityService.record` call — differing only in:
